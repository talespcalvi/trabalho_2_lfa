Para rodar o código basta ter um arquivo .txt como o já nesse .zip com a descrição da grámatica e rodar o código pelo terminal normalmente.
(python trabalho_lfa.py)

O código gera dois arquivos .txt, um para mostrar a gramática limpa e outro para mostrá-la na Forma Normal de Chomsky.

O teste das palavra é mostrado no terminal e na linha 349, no trecho:

---------------------------------------------------------------------------------
# Definir as palavras para o teste comparativo
palavras_teste = ["b", "ab", "aba", "aaba", "bbb", "a", "aa", "bb", "c", "ac"] 
---------------------------------------------------------------------------------

Pode-se alterar as palavras que serão testadas.
